# Share 모바일 UI/UX 검토 시안

2026-09-29 대화에서 만든 가상 데이터 기반 시안을 보관한다. 실제 앱에 적용한 코드와 구분한다. 각 HTML은 Codex inline visualization용 fragment로, 호스트가 제공하는 Lucide·Tweak·선택 상태 저장을 선택적으로 사용한다. 일반 HTML 문서/배포 페이지가 아니다.

| 파일 | 검토 내용 | 현재 판단 |
|---|---|---|
| share-layout-comparison.html | 5탭과 3영역 비교 | 기능 생략이 많아 3탭 전환 보류 |
| share-five-tab-structure.html | 5탭 기능 보존 구조 | 정보 대응표 확인용 |
| share-report-reader.html | 리포트형 홈, 기록 비교, 집중 읽기 | 홈 교체 보류 |
| share-guided-home.html | 기존 홈 구성에서 회차·유형 상세 조회 유도 | 최신 동선 검토안 |

홈은 현재 구성을 바탕으로 첫 행동 하나를 강조하고 정보 행을 관련 데이터 조회로 연결한다. 분석은 설명과 다음 행동을 먼저 보여 주되, 유형 비교용 가로 막대와 회차별 변화 시각화는 근거로 유지하는 방향으로 후속 보완한다. 레이더 차트는 대체 후보다.

워크로그의 기능 보존 대응표와 동선 명세를 함께 읽는다. 재시험 저장·기간/테마 설정·전체 데이터·원본 이미지·오류 상태 등은 실제 기능 유지 대상이며 시안에서 모두 구현하지 않았다. 시안이 실제 배포본과 동일하거나 최적안으로 사용자 검증되었다고 해석하지 않는다.
