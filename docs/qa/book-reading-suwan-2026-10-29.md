# 영독·수완 등록: 무료 구조 검증

## 확인 범위

사용자가 변환한 좌본문·우해석 PDF 4개를 PDF.js로 전체 조사하고, 공유 지문·해설 표제 누락·페이지 연결이 있는 부분은 렌더링하여 확인했다. LLM 호출, Batch 제출, 운영 등록 및 재파싱은 하지 않았다.

| 분류 | 페이지 | 원문 문항 | 지문 묶음 |
| --- | ---: | ---: | ---: |
| 영독 상 | 108 | 108 | 106 |
| 영독 하 | 117 | 120 | 105 |
| 수완 유형편 | 79 | 79 | 75 |
| 수완 실전편 | 135 | 140 | 125 |

447문항의 출처 키는 기존 HWP에서 별도 조사한 목록과 대조했다. 영독은 강/Mini Test 회차, 수완은 유형/실전·강/회차·Practice/연습문제를 구별한다. 모든 묶음은 최대 2페이지이며 미배정 페이지·중복 키·정답 수 불일치가 없다.

## 주의 경계

- 영독 하 Mini Test 2회 26~28번: 89~90쪽을 함께 보존한다. 28번은 `[해설]` 표제가 없지만 실제 인쇄 풀이가 있다.
- 수완 유형 13강: Practice 1~2, 연습문제 1~2, 3~5는 서로 다른 공유 묶음이다. 79쪽의 앞부분 연결 지문을 버리지 않는다.
- 수완 실전의 양쪽 출처 반복은 한 문항이다. 각 회차 43~45번은 앞쪽의 공통 지문과 다음 쪽의 발문을 함께 처리한다.
- `[31~34] 다음 빈칸`, `[36~37] 주어진 글 다음`, `[38~39] 글의 흐름`은 독립 문항 안내이므로 공유 지문으로 합치지 않는다.
- 변환된 `[정답 ]` 등 표제 공백과 출처 괄호 위치 차이를 메타데이터 판별에 허용한다. 원문 본문을 정규식으로 재작성하지 않는다.

`tests/fixtures/book-profile-pages.json`은 실제 페이지별 구조에서 본문을 대체한 회귀 자료다. 모든 원문 문항 키·정답 표제·공유 범위·연결 여부를 검사하되 교재 본문은 넣지 않는다. 독립 기대 목록은 강/회차별 번호로 구성하여 파서 자체 결과를 정답으로 쓰지 않는다.

## 등록 및 검증

기존 교재 Batch 워커의 원본 이미지 대조·필드 복구·풀이/어휘 보완·검증 후 게시를 그대로 사용한다. 코드가 원문 정답·문항 수·공유 번호 누락·분류 불일치를 발견하면 유료 매핑 전에 보류한다. 매핑 후에는 누락/중복 원문 범위와 문항 식별자를 검사하며, 해설 표제가 빠져도 실제 인쇄 풀이를 연결하도록 매핑 및 이미지 검증 지시를 보완했다.

기출·주차별·채점의 라우팅과 처리 코드는 변경하지 않는다. 기존 영어 출처 키와 검증 지문 묶음의 필드 형태도 유지한다. 새 프로필은 현재 확인한 좌본문·우해석 서식 대상이며 임의 PDF 서식 전체를 지원한다는 의미는 아니다.

## DB 및 출시

`supabase/migrations/20261029071858_book_reading_suwan_profiles.sql`은 등록 RPC 허용 교재와 분권, 제목 생성만 확장한다. 기존 문항·해설·원문·검증·작업의 데이터 변경문은 없다. 로컬 PGlite에서 반복 적용, 네 프로필 예약·재사용·분류 수정, 기존 119문항/검증 유지, 서비스 역할 권한 제한을 검사한다.

원격 DB 적용·커밋·배포는 별도 단계다. 유료 생성/원본 이미지 판정의 실제 정확도는 이번 무료 구조 검증만으로 보장하지 않는다.
