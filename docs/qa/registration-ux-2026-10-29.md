# 등록 화면 점검 — 2026-10-29

## 운영에서 확인한 범위

- `edunote-psi.vercel.app`에서 영독 상·하, 수완 유형편·실전편을 각각 선택했고 교재 제목과 분권이 일치했다. 파일을 선택하지 않은 교재 등록 버튼은 비활성화되어 있었다.
- 기출에는 시행 정보, 문제지, 별도 해설지, 일괄 해설 등록이 표시되었다. 기존 문제 검색은 2,091문항, 기존 수특 영어 상 자료는 119문항으로 조회되었다.
- 기존 해설 25번 누락 작업은 미완료와 해당 번호·연결 실패 사유를 표시했다.
- 기존 주차의 현황·채점 화면, 설정의 확정 정답 자료와 원본 PDF 2개를 조회했다.
- 실제 등록·업로드·재시도·채점 저장·재파싱·유료 API 호출은 하지 않았다. 이 점검은 조회·선택 UI 검증이며 실제 등록 실행 검증을 대신하지 않는다.

## 로컬 개선

- 교재 파일을 먼저 고를 수 있다. 알려진 파일명으로 교재·분권을 채우되 학년도는 교재 표지 기준으로 사용자가 확인한다.
- PDF 형식·크기, 교재·분권 불일치, 자료 조회 실패를 접수 전에 표시한다. 등록 준비 여부에 맞춰 실행 버튼을 제어한다.
- 교재/기출을 전환해도 방문한 폼의 선택을 보존한다. 기출은 문제지가 필수이고 해설지는 선택임을 명시한다.
- 사용자 후속 요청으로 입력 영역을 최대 768px 한 열로 줄였다. 교재 폼을 기본으로 표시하고 작은 교재/기출 전환과 학년도/교재/분권 선택을 사용한다. 처리 내역은 아래 독립 영역으로 분리했다. 반복 안내와 중첩 카드를 줄였다.
- 기존 파싱·배치·원본 검증·풀이·어휘·재시도 API와 주차별 기능은 변경하지 않았다. DB 변경도 없다.

## 검증

- `scripts/preview-registration-ui.mjs`는 가짜 환경변수와 GET 전용 응답을 쓰는 독립 미리보기다. 외부 등록 요청은 차단한다.
- 실제 영독 하 파일을 로컬에서 선택하니 영어독해연습·하, 117페이지·1.7MB가 표시되었다. 등록은 누르지 않았다.
- 390px 모바일과 기본 데스크톱, 라이트·다크 화면을 확인했다. 가로 넘침은 없었고 자료 종류 전환 후 선택이 유지되었다.
- 유닛 검증은 네 파일명의 자동 선택, 분권 불일치 차단, 파일 크기·형식, 선택 보존, 별도 문제지·해설지 필수 조건을 포함한다. 실제 AI 호출은 없다.
- 첫 개선안의 `npm run check -- --maxWorkers=2` 통과: 타입 오류 0, 린트 오류 0(기존 경고 21개 유지), 182개 파일·1,590개 테스트 성공. 후속 간소화안은 아래 검증 기록으로 구별한다.

### 후속 간소화안 화면 검증

- 큰 자료 종류·교재 카드를 제거하고, 교재 기본 폼과 작은 교재/기출 전환, 학년도/교재/분권 선택 상자로 변경했다. 분류 수정 대화상자의 기존 조작은 유지한다.
- 처리 내역은 입력 폼 아래에서 조회한다. 미완료 번호와 실패 사유, 상세 보기·재시도 기능은 그대로다.
- 기출도 파일부터 선택하고 시행 정보를 확인한다. 별도 문제지/해설지 선택과 해설만 추가하는 기존 흐름을 유지한다.
- 기본 데스크톱과 390px 모바일에서 라이트·다크 화면을 확인했다. 가로 넘침이 없고, 자료 종류 전환 후 분류가 유지되며 빈 기출 등록 버튼은 비활성화 상태였다. 임시 화면 크기는 복원했다.
- 교재 기본 노출·처리 내역 순서와 기존 등록 회귀 테스트 17개가 통과했다. 실제 파일 전송이나 등록 버튼 실행은 하지 않았다.
- 간소화 후 `npm run check -- --maxWorkers=2` 최종 통과: 타입·린트 오류 0, 기존 경고 21개 유지, 182개 파일·1,591개 테스트 성공.

## 사용상 경계

- 파일 하나를 접수하는 흐름이다. 상·하나 유형·실전 여러 PDF를 동시에 접수하는 기능은 추가하지 않았다.
- 파일명은 선택 보조 정보다. 책에 적힌 학년도와 최종 등록 대상을 확인해야 한다. 파일명 자체가 잘못된 경우 이름을 고치고 다시 선택해야 한다.
- 비동기 배치이므로 접수 직후 문제은행에서 바로 사용할 수 있는 것은 아니다. 완료·미완료 상태는 기존 처리 내역에서 확인한다.
- 최초 검토는 로컬 작업이었다. 아래 운영 배포 기록 이후에는 배포된 화면과 일치한다. Git 커밋·푸시는 별도로 하지 않았다.
