# 2026-08-27 — 출력 범위 분할 파싱 + 해설지통합형 분할

두 주제. 공통 배경: "PDF를 자르지 말고, 매 콜 통째로 보내되 출력만 번호 범위로 나눈다"
구조로의 전환. 프롬프트 캐싱(예열 1콜 1.25배 → 이후 콜 0.1배)이 성립 조건이다.

## 1. 해설지통합형(진단평가) 분할 파싱

문항+정답+해설이 한 문서인 통합형은 통짜 1콜이었다. "문항부 전체 → 해설부(끝 1~2p)"
배치가 고정임을 이용해, "정답 및 해설" 헤더 페이지를 찾아(LLM 0콜) 문항부는 문제지형
청킹 파이프라인, 해설부는 기존 통짜 파서로 나눠 병렬 파싱 후 번호로 병합한다.

- `findExplanationSectionStartPage`: 헤더급 마커만, 페이지 첫머리 160자 안에서만
  (문항 안 "[해설]" 오탐 방지). 못 찾으면 기존 통짜 폴백 — 라우트 무변경.
- `mergeProblemStructureWithAnswerItems`: 구조는 문항부, 정답·해설·소문항은 해설부.
  어느 쪽 결손이든 다른 쪽 데이터는 살린다.
- `pageStartsWithQuestion` 머리글 스킵: "2 / 7 I110:…" 류 쪽번호+문서코드를 건너뛰고
  판정 — 숭문형에서 경계 정렬이 실제로 작동하게 됨.

**부작용 가능 지점**: parse-answers 라우트를 타는 모든 해설지 업로드. 분할 경로에서
숭문형처럼 pdf-lib 슬라이스가 백지가 되는 PDF는 렌더 재조립(이미지 PDF)으로 들어가
입력 토큰이 늘 수 있다. 스캔형·이미지·복수 파일은 전부 통짜 폴백.

**수동 확인**: 숭문 진단평가 재업로드 — 서버 로그에 "해설 섹션 감지 p6" 확인, 문항
수·해설 채움 동일한지.

## 2. 기출은행 문제지·해설지 — 출력 범위 분할 전환

```
예열 콜 (max_tokens 0, 캐시 생성)  →  범위 콜 전부 병렬 (캐시 히트 0.1배)
문제지: 5범위(18-23/24-29/30-35/36-40/41-45), sonnet
해설지: 4범위(18-24/25-31/32-38/39-45), opus — 평가원형 라우트 전환, 학평형은 whole 유지
```

실측 (2026-08-26~27, 실제 모평 PDF):

| 대상 | whole | 입력 청킹 | 범위 분할 |
|---|---|---|---|
| 문제지 8p | 256s | 133s | **69s** (문항·지문 동일) |
| 해설지 31p | **전체 실패** (16k 잘림) | — | **144s, 28/28 완주** |

- `client.ts`: `callClaudeTextDetailed` — usage(캐시 포함)·stop_reason 반환 + 전 호출 로깅.
- `exam-bank.ts`: 범용 코어 `rangedParseCall`/`prewarmPdfCache`, 문제지·해설지 파서가 공유.
- 해석 원문 강제: 프롬프트에 "요약·축약·의역 금지" — 41~45 공유 해석 축약(280자)이
  전문(1,302자)으로 복원됨을 실측.
- 도표 껍데기 필터 `isChartShellQuestion`: 범위 지시가 "도표 제외" 규칙을 이기고 지문 없는
  도표 문항을 내는 실측 사례(25번) — 프롬프트가 아니라 병합 코드에서 결정적으로 거른다.
- 필터 대응: 매 콜 문서 전체가 입력이지만 필터는 출력 기준 — 걸린 범위만 skip, 결손 번호 보고.

**부작용 가능 지점**:
- exam-bank POST 응답 `skipped_pages` 의 의미가 페이지 번호 → **결손 문항 번호**로 변경
  (필드명은 하위호환 유지). 클라 결손 표시 문구가 "쪽"으로 읽는다면 어색할 수 있음.
- 병렬 5콜 + 예열이라 rate limit 소모 순간치가 커짐. 41~45 범위가 실패하면 장문 5문항이
  통째로 결손 (범위 = 결손 단위).
- 입력 청킹 경로(runParsePipeline)는 exam-bank 라우트에서 제거 — 주간 문제지형은 계속 사용.
- 학평형 해설 라우트(upload-explanation)는 whole 유지 — Ranged 미실측이라 보류.

**수동 확인**: 기출 PDF 업로드 1회 — 소요 시간(~1분), 41~45 지문·해설, 도표 문항 미저장 확인.
