## 홈

**이전** — 배경 그라데이션(`#EBF3FF→#FFF`) 위 흰 카드들
- 히어로 카드: 이름 + "최근 시험 · 5/1" + 40px 숫자 타일 2개(시험 파랑 / 단어 초록)
- 4열 스탯 카드: `8% 시험 평균` `71% 단어 평균` `50% 과제 평균` `100% 출결 현황`
- "이번 주 잘한 것" 이모지 칩: 🏃 출석 100% · 🌱 관계사 개선 중
- 과제 제출률 막대 차트
- 지표마다 색이 달랐다 (시험 파랑 / 단어 초록 / 과제 주황)

**이후** — 흰 캔버스 위 `#F9FAFB` 카드 4장
- ① 이번 주: 파랑 eyebrow + 23px 헤드라인 한 문장 + 점 팩트 리스트(주의는 빨강 점)
- ② 선생님 코멘트 (있을 때만)
- ③ 할 일 (오답 있을 때만) — "진단평가 오답 28문항 / 풀기 ›"
- ④ 기간 요약 — 행 4개(시험·단어·과제·출석) + 라인 차트(영역 채움·반 평균 점선)
- 색은 파랑/빨강 두 가지 의미로만

## 성적 → 기록

**이전** — "시험 점수 추이" / "단어 점수 추이" Recharts 카드 2개 + 회차별 성적 목록

**이후** — 추이 차트는 홈 요약으로 흡수. 22px "회차별 기록" + `시즌 | 전체 기간` 세그먼트,
회차 아코디언(최신 1개 펼침, 흰 칩 `시험 2/4 반 -12%`), 하단 출결 현황 카드
