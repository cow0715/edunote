# 공유 리포트(share 페이지) 전면 리디자인

원본 사양: `학습 리포트 디자인 벤치마킹/design_handoff_share_report/README.md`

정보 구조를 **"이번 주 한 줄 → 할 일 → 기간 요약 → 코멘트"** 로 바꾸고,
색을 카테고리 구분이 아니라 **의미(파랑=선택/긍정, 빨강=주의)** 에만 쓰도록 정리했다.
탭도 5개로 재편: 홈 · 기록 · 분석 · 오답 · 단어.

---

## 1. 전역 토큰 · 공통 표면

`share-tokens.ts` 에 TDS 팔레트(`T`)와 `rateColor` / `deltaColor` / `PRESS*` / `riseStyle` 을 모았다.
`share-ui.tsx` 에 `Segmented` `Chip` `Chevron` `CountUp` `AccordionRow` 를 두고 탭들이 이것만 조합한다.
`Card` 는 흰 배경 + 파란 그림자에서 `#F9FAFB` · 20px · 그림자 없음으로 바뀌었다.
모션 키프레임(`share-rise/draw/area-in/sheet-up/pop/shake`)은 `globals.css` 에 있다.

**부작용 가능 지점**
- `chart-colors.ts` 의 `statusColor` 를 "60% 미만 빨강, 아니면 잉크"로 단순화하고 `isDark` 인자를 없앴다.
  → `concept-radar-chart.tsx` (`/dev` 플레이그라운드에서 쓰임) 가 같이 바뀌었다.
- `share-utils.ts` 의 `ATT_STYLE` → `ATT_BADGE` 로 이름·모양이 바뀌었다 (Tailwind 클래스 → `{color, bg}`).
- **share 화면은 라이트 전용이 됐다.** `use-share-theme.ts` 삭제, 헤더의 다크모드 토글 제거,
  share 아래 `dark:` 클래스 0개. 다크 매핑은 handoff README 가 범위 밖으로 지정했다.
  화면에 남은 검정(`#191F28`)은 다크 테마가 아니라 **집중 모드 패널**이다.

**수동 확인** — `/dev` 페이지의 차트들이 여전히 뜨는지 (컴포넌트는 삭제하지 않았다).

## 2. 셸 (헤더 · 탭바 · 기간 시트)

헤더가 "학년·학교·반 + 이름 + 기간 pill" 로 바뀌고, 기간 선택은 바텀시트가 됐다.
하단 탭바는 5탭 + 슬라이딩 인디케이터.

**부작용 가능 지점**
- `/api/share/[token]` 응답의 `periodOptions` 에 **`week_count` 가 추가**됐다.
  기간 시트가 "N회차"를 보여주고 0회차 기간을 못 고르게 막는 데 쓴다.
  `week` 테이블을 `class_period_id` 로 한 번 더 조회한다 (id 만 select).
- 같은 라우트에 **`?scope=all`** 이 추가됐다 (기록 탭 "전체 기간" 전용).
  이때 기간 경계 필터(`isWeekInPeriod`)를 통째로 건너뛰므로, 다른 곳에서 이 파라미터를 붙이면
  스코프가 조용히 넓어진다.
- 기간을 바꾸면 오답 아코디언 펼침 상태와 스크롤이 초기화된다.

**수동 확인** — 기간이 2개 이상인 학생으로 시트를 열어 회차 수·현재 배지·0회차 비활성 확인.

## 3. 홈 탭

카드 4장: 이번 주(23px 헤드라인 + 점 팩트 리스트) · 선생님 코멘트 · 할 일 · 기간 요약.
기간 요약 행을 누르면 아래 라인 차트(`summary-chart.tsx`)의 시리즈가 바뀌고,
점/라벨을 누르면 기록 탭 해당 회차로 간다.

**부작용 가능 지점**
- `buildWeeklyHeadline` 의 **우선순위 규칙이 통째로 바뀌었다** (만점 → 단어만 → 첫 회차 → 방향 조합).
- `buildWeeklyNotes`(잘한 점/챙길 점) 가 **삭제되고** `buildWeeklyFacts` 로 대체됐다.
  → `design-data/dump-screen.tsx` 가 `latest.notes` 를 쓰고 있어 `latest.facts` 로 고쳤다.
- 기간 요약의 값은 **기간 평균**, 델타는 "최신 회차의 지난 회차 대비 · 기간 평균의 반 평균 대비" 다.
  README 에 값 정의가 없어 판단한 부분이라, 숫자 해석이 기대와 다르면 여기다.
- 홈에 있던 과제 막대 차트와 최근 8주 스파크라인은 기간 요약 카드로 흡수됐다
  (`homeworkData` / `recentTrend` 는 모델에 남아 있지만 홈에서 더는 그리지 않는다).

**수동 확인** — 시험이 없는 기간, 회차 1개뿐인 기간(그래프 대신 안내 문구).

## 4. 기록 탭

회차 아코디언(기본 펼침은 최신 1개) + 출결 현황. 홈에 있던 추이 차트는 홈으로 갔다.
`history-utils.ts` 의 `buildHistoryGroups` 는 순수 함수라
"이 기간"(useShareModel 결과)과 "전체 기간"(scope=all 응답)이 **같은 코드를 탄다**.

**부작용 가능 지점**
- 점수 미입력 회차(`reading_correct === null`)는 시험 칩을 그리지 않는다 — 안 그러면 `null/23` 이 찍힌다.
- 반 평균 차이가 0이면 칩에 표시하지 않는다.
- "전체 기간" 은 토글하기 전에는 요청하지 않는다(`enabled`). 응답이 하나 더 늘어난다.

**수동 확인** — 특강반 등 기간이 여러 개인 학생으로 "전체 기간" 토글 → 기간 그룹 헤더.

## 5. 분석 탭

Recharts 레이더·도넛을 인라인 SVG 로 바꿨다 — 카테고리마다 색을 배정하던 12색 팔레트를 없애기 위해서다.
유형별 오답률은 가로 막대 목록(상위 8개 + 더 보기), 정렬은 기존 `sortByWeakness`(Wilson 하한) 그대로.

**부작용 가능 지점**
- 약점 패턴 색이 4색(rose/orange/purple/emerald) → **3의미**(고착·악화 빨강 / 기복 회색 / 개선 파랑)로 줄었다.
- 패턴 카드의 주차별 미니 바는 `allWeekNumbers`(이 기간 전체 회차)를 받아 미출제 자리를 3px 로 남긴다.
- 표본 2개 이하 유형은 오답률 100%여도 빨강으로 강조하지 않는다.

## 6. 오답 탭 + 진단평가 다시풀기 (신규)

세그먼트 + 파랑/다크 CTA + 주차 아코디언. **빈 상태를 3종으로 나눴다** —
"이 기간엔 진단평가가 없어요" / "진단평가 오답이 없어요" / "문항별 오답 기록이 없어요".
기록 누락을 "잘했다"로 오해하지 않게 하는 게 목적이다.

`reading-review.tsx` 는 오답 탭 위에 덮는 전체화면이다. **별도 라우트가 아니다** —
문항·선지·해설이 이미 로드돼 있어서 라우트로 빼면 같은 데이터를 다시 받는다.
**채점도 서버에 보내지 않는다** (DB 를 건드리지 않는 순수 복습 화면).

시작 지점이 두 개다: 상단 CTA(전체) 와 **회차 아코디언 안의 `ReviewActionRow`(그 회차만)**.
단어 재시험이 회차 단위인 것과 맞췄다 — 한 회차 분량이 학생이 앉은자리에서 끝낼 크기다.
`reviewScope` 가 `'all' | weekId | null` 이고, 값이 바뀌면 `key` 로 진행 상태를 새로 잡는다.

피드백 박스는 선지 아래가 아니라 **하단 버튼 위 고정 영역**에 둔다. 지문이 길면 확인을 눌러도
정답·해설이 화면 밖에 남는데, 스크롤 보정(scrollIntoView / scrollTo)은 박스가 붙으며 늘어난
높이가 반영되기 전에 시작돼 중간에서 잘렸다. 스크롤을 없애는 쪽이 확실하다.

**부작용 가능 지점**
- `buildReviewQuestions` 는 **객관식(선지 저장분)과 OX** 만 고른다. 서술형·find_error·multi_select 는 제외.
  OX 는 선지가 저장돼 있지 않아도 정답키(`parseOXAnswerKey`)에서 O/X · T/F 두 선택지를 만든다.
  판정만 묻고 수정어는 정답 옆에 적어준다 (`answerNote`).
  CTA 문항 수가 오답 총계보다 적을 수 있고, 그때는 힌트에 "객관식·OX 오답만"이라고 적는다.
  대상이 0이면 CTA 가 "오답 N문항 보기"로 폴백한다.
- 밑줄 OX 는 `question_number` 가 곧 지문의 밑줄 번호라(sub_label 없음) 같은 원문자(①)로 부른다.
  소문항이 있는 시험지는 `11번a` 형태 — 이때 밑줄 번호는 해설에만 있다.
- 정오 색이 share 전용으로 갈라졌다: `SHARE_WRONG_CLASS`(빨강 취소선) / `SHARE_RIGHT_CLASS`(잉크).
  **채점 화면(`components/grade/*`)의 초록=정답은 그대로 뒀다** — 선생님용이고 관습이 더 강하다.
  그래서 예문 유형 인라인 문장 안에서는 여전히 초록이 보인다.
- 유의/반의 칩이 blue/amber → 전부 회색.

## 7. 단어 탭 + 단어 재시험

단어 탭: 검색 + 칩(전체/오답/재시험 남음/미작성만) + 주차 아코디언.
주차·지문·품사·예문 셀렉트는 "상세 조건" 뒤로 접었다 (없애면 기능 후퇴라 유지).

재시험 화면: **타이머·채점·라운드 로직은 그대로 두고 렌더만 교체**했다.
다크 헤더 + 다크 단어 카드 + 회색 입력창, 타이머는 20초 이하에서 빨강.

**부작용 가능 지점**
- `VocabStudyMode` 에 `'unanswered'` 가 추가됐다 (오답 중 답을 아예 안 쓴 것).
  오답 탭 → 단어 탭 프리셋 이동이 이 타입을 공유한다.
- 단어 행의 정답 뜻은 `word.correct_answer ?? wrongAnswer.example_answer`, 둘 다 없으면 정답 쪽을 생략한다
  (예전엔 `→ -` 가 찍혔다).
- 재시험 결과 문구에서 "라운드" 를 뺐다: `이번 라운드` → `이번 재시험`,
  `다음 라운드 (N개 남음)` → `남은 N개 다시 풀기`.
- 재시험 페이지도 라이트 전용이 됐다 (`useSyncExternalStore` 테마 구독 제거).

**수동 확인** — 재시험 제출 → 결과 → "남은 N개 다시 풀기" → 기록 탭 재시험 칩이 갱신되는지.

## 커밋 시점 검증

`npm run check` — 0 errors / 24 warnings(기존 대비 -5) / 40 test files · 560 tests 통과.

**주의**: 아래 커밋들은 주제 단위로 나눈 것이라 **개별 커밋 하나만으로는 타입체크가 통과하지 않는다.**
(토큰 도입과 탭 재작성이 서로를 참조한다.) 전체 시리즈가 적용된 상태가 초록불이다.

## 남은 일

- **다크 테마 매핑** — handoff README 가 범위 밖으로 지정. TDS 다크 스케일로 토큰 한 벌 추가 필요.
  집중 모드 패널(`#191F28`)이 다크에서 배경과 같은 색이 되는 문제부터 정해야 한다.
- `학습 리포트 디자인 벤치마킹/` 폴더는 **프로토타입 데이터에 학생 실명이 들어 있다**(`강상섭`).
  `.gitignore` 가 같은 이유로 `design-data/` 를 제외하고 있으므로, 이 폴더도 커밋 제외 또는 무시 대상 검토 필요.
- `/dev` 플레이그라운드가 참조 중이라 옛 Recharts 차트 파일은 삭제하지 않았다.
- **다시풀기 대상이 아직 절반이다.** 개발 DB reading 문항 171개 중 다시 풀 수 있는 건 43개
  (객관식 28 + OX 15). 나머지 중 **77개는 "객관식인데 `choices`/`correct_answer` 가 비어 있어서"**
  빠진다 — 유형의 한계가 아니라 파싱 단계의 데이터 공백이다. 채우면 대상이 105+ 로 늘어난다.
