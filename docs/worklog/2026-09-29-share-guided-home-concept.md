# 현재 홈 기반 상세 조회 동선 시안

상태: 앱 수정 없는 인터랙션 검토안. 현재 배포본을 이번 작업에서 다시 접속해 비교하지는 않았다. 앞서 확인한 코드·사양의 최근 수업/코멘트/할 일/기간 요약 구조를 바탕으로 한다. 재설계 홈의 최근 수업/기간 요약 탭 분리는 적용하지 않는다.

## 실제 변경 제안

1. 최근 수업 카드의 시험·단어·과제 행은 그 회차 결과로 연결한다.
2. 첫 행동 하나를 최근 수업 카드 아래에 강조한다. 예시 데이터에서는 ‘틀린 2문제 확인하기’이며, 자동 시험 시작이 아니라 해당 회차 오답 조회다. 할 일 카드에서 같은 독해 액션을 반복하지 않는다.
3. 코멘트 뒤의 유형 연결은 누적 유형 데이터에서 근거가 확인된 항목에만 제공한다. 임의로 자유 텍스트를 해석해 잘못된 유형으로 연결하지 않는다.
4. 재시험 남은 단어는 기간+회차+재시험 대기 조건을 함께 넘겨준다.
5. 기간 요약 지표는 ‘추이 보기/선택됨’, 회차 날짜는 상세 이동, 출결 행은 정규/클리닉에 맞는 상세로 연결한다. 그래프 전환과 페이지 이동의 표시를 구분한다.

## 연결 규칙

| 출발 | 목적지 조건 | 돌아올 곳 |
|---|---|---|
| 최근 수업 점수/과제 | 선택 기간 + 최근 회차 결과 | 누른 홈 결과 행 |
| 틀린 2문제 | 선택 기간 + 최근 회차 독해 오답 | 홈의 첫 행동 |
| 문항 행 | 목록의 회차/유형 유지 + 해당 문항 | 동일 목록의 해당 행 |
| 다음/이전 문항 | 현재 목록에 포함된 문항만 이동 | 원래 목록 |
| 유형 근거 확인 | 선택 기간 + 해당 유형 통계 | 코멘트 아래 액션 |
| 유형 오답 보기 | 선택 기간 전체 + 해당 유형 | 유형 분석 |
| 재시험 2개 남음 | 최근 회차 + 미통과 단어 | 홈의 남은 복습 행 |
| 추이의 9/17 | 해당 회차 기록 | 선택 지표를 유지한 홈 |
| 클리닉 결석 | 해당 기간 + 클리닉 | 홈 출결 행 |

## 첫 행동 결정 제안

우선순위는 제품 정책 후보이며 아직 실사용 검증 전이다.

- 최근 회차에 조회 가능한 독해 오답이 있으면: 해당 오답 보기.
- 독해 오답이 없고 단어 재시험이 남아 있으면: 해당 회차의 남은 단어 보기.
- 둘 다 없으면: 최근 수업 결과 보기 또는 기간 변화 보기. 존재하지 않는 할 일을 만들지 않는다.
- 점수만 있고 문항 자료가 없으면: ‘오답 2문제’라는 실행 불가능한 진입을 만들지 않는다. 수업 결과에 문항 자료 미등록을 구분한다.
- 홈의 주요 행동은 항상 하나. 나머지 정보 행은 보조 진입점이다.

## 시안 범위

`share-guided-home.html`은 가상 데이터로 조회 경로를 체험한다. 최근 회차 독해 2문항, 과거 빈칸 1문항, 현재 회차 단어 4개(2개 통과/2개 대기), 과거 단어 1개가 포함되어 회차/상태 필터 혼입을 확인할 수 있다.

독해 다시 풀기는 사용자가 명시적으로 시작하는 로컬 체험으로 정답/해설 확인까지 제공한다. 실제 성적을 저장하지 않는다. 단어 재시험의 타이머·입력·서버 저장, 전체 학습 단어장, 상세 필터, 기간/테마 설정, 전체 기간 기록, 모든 원본 이미지/소문항 및 오류 상태는 앞선 기능 보존 대응표의 유지 대상이다. 이번 시안에서 전부 재구현한 것은 아니다.

복귀는 조회 조건과 펼침 항목을 저장하고, 출발 버튼으로 포커스를 돌려 그 항목이 보이도록 한다. 스크롤의 정확한 픽셀 복원, 모바일 브라우저 하드웨어 뒤로 가기/URL 연동은 실제 구현의 검증 과제로 남긴다.

## 확인 결과

- 스크립트: 홈→최신 오답→다음 문항→목록→홈, 최신 회차 대기 단어의 범위, 유형 통계→유형별 문항→복귀, 로컬 정답 확인, 클리닉 결석, 홈 차트 지표 복원 확인.
- 브라우저: 9/24의 2문항 진입과 전문 읽기, 목록 복귀 시 같은 문항 포커스, 홈 복귀 시 첫 행동 포커스 확인.
- 375px 뷰포트에서 홈 가로 넘침 없음 확인. 사용자 테스트·실제 배포 회귀 검증 완료를 뜻하지 않는다.
- 앱 소스, 기존 디자인 사양, 배포 상태는 변경하지 않았다.
