# Share 모바일 재구성 — 기능 보존을 먼저 검증하는 5탭 개선안

상태: 구조 검토안. 앱 코드와 design.md는 수정하지 않음. 3탭 전환 권고는 철회하고 비교 후보로 보류한다. 토스 계열사 조사에서 얻은 정보 위계·짧은 선택·읽기 화면 분리 원칙만 적용한다. 기존 구현은 다른 작업의 변경까지 포함한 2026-09-29 워킹 트리 기준이다.

## 판단

현재 기능을 유지하는 5탭 개선을 우선한다. 기존 3탭 시안은 과제·출결·반 평균·약점 패턴·재시험 등 중요한 내용을 생략했으므로 전환 효과의 근거로 사용할 수 없다. 화면에 적게 보이는 것과 기능을 찾기 쉬운 것은 다르다.

학생의 ‘결과 확인 → 필요한 복습 → 다시 결과 확인’ 흐름은 탭을 합치지 않아도 연결할 수 있다. 부모의 ‘코멘트 → 과제·출결 → 성적 변화’ 흐름도 함께 유지한다. 역할 선택 화면은 추가하지 않는다.

## 화면별 구체적인 개선

### 홈: 결과·코멘트·할 일·기간 요약을 모두 유지

현재 사양의 순서를 기준으로 한다. 이번 안에서 코멘트를 하단으로 옮기거나 없애지 않는다.

1. 최근 수업: 헤드라인을 가장 강하게, 시험·단어·과제 팩트와 출결을 그 아래 같은 맥락으로 배치한다.
2. 선생님 코멘트: 최근 코멘트 본문을 유지하고 이전 코멘트는 개수를 보이는 펼침으로 제공한다.
3. 할 일: 독해 오답과 단어 재시험 상태를 각각 표시한다. ‘오답 보기’는 해당 회차로 이동한다.
4. 기간 요약: 지표별 평균·증감·반 비교를 모두 남긴다. 한 번에 한 그래프만 바꾸되 다른 지표 값은 사라지지 않는다.

홈 전체를 짧게 만들겠다는 이유로 과제·출결·비교값을 접는 것은 이번 개선에서 제외한다. 정보량이 많아 첫 화면에 모두 들어오지 않는 것은 허용한다.

### 기록: 훑어볼 수 있는 회차 헤더 + 펼쳐 읽는 세부 내용

점수·재시험·과제·출결은 회차 헤더에 남긴다. 오답 유형과 코멘트만 내부에 둔다. 전체 기간을 선택해도 다른 탭의 범위까지 몰래 바뀌지 않는다. 출결 현황은 정규/클리닉 구분, 월 범위와 범례까지 유지한다.

### 분석: 읽을 수 있는 수치와 판단 근거

유형명·오답/출제 수·오답률을 함께 보여 준다. 작은 레이더의 시각적 크기를 줄이거나 제거하더라도 영역별 수치·태그가 없어지면 안 된다. 레이더를 수평 비교 행으로 대체하는 것은 표현 변경 후보이며, 실제 변경 시 디자인 사양도 함께 갱신한다.

약점 패턴은 여전히 독립 섹션으로 둔다. 고착/악화/기복/개선과 회차별 근거를 남긴다. 유형을 누르면 ‘9월 · 빈칸 추론’처럼 적용 범위를 표시한 목록으로 연결하고, 돌아오면 분석의 원래 위치를 복원한다.

### 오답: 찾기와 읽기를 분리하되 답·해설을 숨겨 버리지 않기

목록의 기본 행: 회차·문제 번호·유형 → 발문 핵심 → 내 답·정답 → 문제·해설 읽기. 긴 지문을 모든 행에 자동으로 펼치지 않는다.

읽기 화면: 번호/발문 → 지문 → 원본 이미지 → 선지 → 내 답·정답 → 해설·첨삭·소문항. 지문 16px/400/1.75, 발문 17px/700/1.6, 해설 15px/1.75. 중첩 카드 패딩을 피하고 하나의 스크롤로 읽는다. 다음/이전 문제와 목록 복귀를 제공한다. 재풀이는 별도 의도를 가진 액션으로 유지한다.

추가 탭 비용이 있으므로 ‘목록에서 펼쳐 읽기’ 대안도 비교해야 한다. 외워 둔 특정 문제 찾기는 목록형이 유리할 수 있지만, 여러 해설을 연속해서 읽는 학생에게는 페이지 왕복이 불리할 수 있다. 별도 읽기가 항상 더 낫다고 확정하지 않는다.

### 단어: 기본 정보는 보이고 긴 참고 정보만 펼침

단어·뜻·상태·내 답/정답은 접지 않는다. 유의어·반의어는 짧으면 유지하고, 긴 파생어·예문·번역은 ‘학습 정보’ 펼침으로 묶는 안을 비교한다. 검색이 접힌 정보에서 일치했으면 일치 위치를 알리거나 해당 부분을 펼쳐야 한다.

상세 조건을 닫아도 ‘2개 적용’만으로 끝내지 않고 실제 적용한 주차/품사 등의 값을 알 수 있어야 한다. 조건 해제와 초기화는 기존 기능을 유지한다.

## 바텀시트 판단을 분리

- 기간 선택: 기존 정보량(기간명·날짜·회차)을 담은 실제 표본으로 인라인/팝오버/시트를 비교한다. 월 이름 두 개만 넣은 시안으로 결론 내리지 않는다.
- 분석 유형의 문항: 여러 긴 문제를 읽는 작업이므로 전용 읽기 화면이 비교 후보다.
- 짧은 설정·복수 조건 선택: 바텀시트가 여전히 유효한 후보다.
- 이번 구조안은 바텀시트 대체안을 확정하거나 구현하지 않는다.

## 다른 작업에 전달할 구현 범위

이 문서는 구현 지시를 실행한 결과가 아니다. 코드를 수정할 후속 작업은 다음을 따른다.

1. 현재 변경 중인 테마·문제 가독성 작업과 diff를 확인한다. 기존 변경을 되돌리지 않는다.
2. 5탭·데이터 계산·전체 기간 조회·단어 재시험 저장 흐름은 유지한다.
3. 우선 오답의 목록/읽기 밀도와 복귀 상태만 변경하여 사용성 확인한다.
4. 그 다음 단어의 긴 참고 내용과 필터 표시를 개선한다.
5. 홈·기록·분석은 지표 삭제 없이 타이포·간격·근거 표시를 조절한다.
6. 승인된 시각 변경은 design.md와 원본 handoff에 동기화하고, 코드 수정 뒤 npm run check를 통과시킨다. 커밋·푸시는 별도 요청 전 수행하지 않는다.

확인 파일: share-client.tsx, tabs/home-tab.tsx, tabs/score-tab.tsx, tabs/analysis-tab.tsx, tabs/wrongnote-tab.tsx, tabs/vocab-tab.tsx, wrong-answer-card.tsx, vocab-word-card.tsx, reading-review.tsx, retake/[weekId]/page.tsx, design.md, handoff README.

## 동반 구조 시안의 범위와 검증

`share-five-tab-structure.html`은 정보 배치 검토용이다. 기존 기능 전체를 재구현한 제품 시안이 아니다. 실제 코드에서 확인한 보존 요구사항의 원장은 위 대응표다.

- 시안에서 동작: 5탭 전환, 최근 문항 목록/전문 읽기 비교, 문제·해설·첨삭 확인, 단어 검색과 상태/상세 필터, 학습 정보 펼침, 출결 수업 구분, 기록 범위 전환.
- 실제 구현을 그대로 유지할 대상이며 시안에서 재현하지 않음: 기간/테마 설정, 단어 재시험의 타이머·입력·채점·저장, 독해 개인 복습 전체 흐름, 원본 이미지와 복합 소문항, 모든 과거 회차 전문, 실제 차트 및 월 이동, 네트워크 오류 상태.
- 문항은 최근 2개, 단어장은 조건을 비교할 4개만 사용한다. 샘플 수는 실제 목록 제한이 아니다. 홈/분석의 통계는 샘플 기간 전체를 표현한다.
- 브라우저에서 최근 문항 진입/복귀·원문/해설/첨삭·유의어 검색을 확인했다. 320/375px 뷰포트 내 읽기/단어 화면에서 가로 넘침이 없음을 확인했다. 5탭, 읽기 대안, 단어 필터, 전체 기간/클리닉 상태는 별도 스크립트로 렌더 전환을 확인했다.
- 실제 기기·글자 확대·장기 데이터·사용자 과제 테스트는 아직 수행하지 않았다. 앱 소스는 수정하지 않았으므로 앱 회귀 테스트 완료를 주장하지 않는다.
