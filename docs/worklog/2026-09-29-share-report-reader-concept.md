# Share 시안: 리포트와 집중 읽기

2026-09-29. 실제 앱 수정 없음. 기존 기능 보존 대응표(`2026-09-29-share-preserved-function-redesign.md`)를 전제로 한 시각·동선 검토안이다. 기존 디자인 사양을 덮어쓰는 구현 확정안이 아니다.

## 이전 시안과 달라진 점

- 홈: 같은 회색 카드 네 개의 반복에서 벗어나, 최근 수업을 하나의 리포트로 구성한다. 결과 헤드라인 → 독해/단어/과제의 같은 기준선 → 반 비교 → 편지 형태의 코멘트 → 복습 액션으로 위계를 만든다. 과제, 출결, 반 비교, 이전 코멘트는 유지한다.
- 홈 누적: 최근 수업과 기간 평균을 별도 내부 탭으로 구분한다. 기간 요약에는 세 지표 평균, 직전 회차 대비, 반 비교, 학생 실선/반 평균 점선, 회차 기록 연결, 출결 연결을 둔다. ‘최근 수업과 기간 요약 분리’를 끄면 같은 내용이 연속으로 이어진다. 내용 삭제가 아닌 탐색 비용 비교다.
- 기록: 날짜와 독해/단어/과제 수치를 열에 맞춰 회차 간 비교가 가능하게 한다. 최신 회차 또는 그래프에서 고른 회차를 펼쳐 반 비교, 재시험, 오답 유형, 코멘트, 복습 연결을 본다. 정규/클리닉 출결은 기록 내부의 출결 탭으로 분리한다.
- 분석: 우선 살펴볼 유형과 관련 문제 진입을 먼저 배치하고, 전체 유형별 오답/출제 수·영역별 정답률·회차별 패턴 근거를 이어 보여 준다. 가장 약한 유형만 남기지 않는다.
- 오답: 목록은 카드 안 긴 전문 대신 회차 아래 문항별 행으로 구분한다. 별도 읽기는 본문 17px 기준, 중첩 패딩 없이 문제·선지·정답·해설·첨삭을 이어 읽는다. 다음/이전 문항으로 이동한다. 기존처럼 목록에서 전문 읽는 대안도 전환 가능하다.
- 단어: 카드 반복 대신 사전 형태로 단어·뜻·출제/오답 상태를 읽는다. 검색과 상태/상세 필터는 유지한다. 긴 예문·파생어를 기본 펼침/접힘으로 비교한다.

## 정보 이동의 비용

기간 요약과 출결은 기존보다 한 번 더 누른다. 최근 수업이나 회차를 빠르게 파악하는 이점이 이 비용보다 큰지 검증해야 한다. 전체 기간 성적과 출결을 자주 보는 학부모에게는 연속 리포트가 더 나을 수 있다. 따라서 탭 분리를 ‘최적’으로 확정하지 않는다.

구조안에서 보존한 정보와 실제 작동을 구분한다. 기간/테마 설정, 단어 재시험 타이머·입력·채점·저장, 독해 개인 복습, 원본 이미지·복합 소문항, 과거 전체 데이터·빈/오류 상태는 기존 기능 보존 대상이다. 이번 시안은 이 기능을 삭제하자는 제안이 아니며 모두 재구현한 것은 아니다. 주된 검토 대상은 보고 읽는 경험이다.

## 시안 검증

가상 데이터. 최근 2회차의 독해 6/10→8/10, 단어 14/20→16/20, 과제 4/5→5/5를 사용한다. 기간 평균은 각각 70%, 75%, 90%다. 분석 유형의 오답 합계는 6/20으로 맞췄다. 반 비교와 직전 회차 비교는 별도 표기한다.

리포트/기간 요약, 회차 연결, 정규·클리닉 출결, 분석 유형에서 문제 읽기와 복귀, 단어 상태 필터와 읽기 설정 전환은 스크립트로 확인했다. 브라우저에서 홈·기간 차트·선택 회차 펼침을 확인했다. 실제 학생 과제 테스트와 앱 회귀 검증은 수행하지 않았다. 앱 코드 수정 없음.
