## 발견하고 수정한 문제

1. **재시험 답안의 학생/주차 소유 범위 누락**
   - 가상 학생 A 토큰으로 같은 주차의 가상 학생 B 답안 ID를 제출했을 때 기존 코드는 200 성공 및 B 답안 변경.
   - 답안 조회/수정에 해당 학생·주차의 `week_score_id` 및 원래 오답 조건 추가.
   - 제출 ID 중 하나라도 허용 범위 밖이면 채점/저장 전 전체 요청 400 차단.
   - 수정 후 동일 실제 HTTP 요청 400, 정상 자기 답안은 200 확인.
2. **재시험 저장 오류를 무시하고 성공 응답**
   - 답안 저장·통계 조회·누적 성적 저장 오류와 변경 건수를 검사하도록 보완.
   - 저장 실패/0건 변경 시 성공 대신 503 반환. 입력 형식과 중복 ID도 사전 검증.
   - 모의 저장 실패 회귀 테스트 통과. 개발 DB의 실제 운영 테이블에 장애용 트리거를 설치하지는 않았다.

## 테스트 데이터와 한계

- 개발 테스트 반 `P0 E2E 임시반 20261019`에 가상 학생 2명, 가상 문제·성적을 생성했다. 해당 반은 보관 상태이며 복원 가능하다.
- 실제 학생/수업은 수정하지 않았다. 별도 권한 검증용 가상 강사/외부 반은 제거했다.
- 모든 P0 항목을 위 방식으로 검증했지만, 모든 실패 경로를 브라우저에서 재현한 것은 아니다. 동시 저장은 두 브라우저 대신 실제 서비스 병렬 요청으로, 저장 오류 응답은 회귀 테스트로 확인했다.
- 수정본은 격리 로컬 서버 + 개발 DB에서 재검증했으며, Vercel 미리보기에는 아직 배포되지 않았다.
- 유료 AI 채점/생성, 운영 인증 후 저장, 모바일 전체 회귀는 이번 검증 범위에서 제외했다.
