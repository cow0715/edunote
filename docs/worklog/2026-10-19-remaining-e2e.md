- 학생 목록/반별 명단 1,000건 초과 조회, 권한 필터·정렬 유지, 중간 페이지 실패 시 부분 성공 금지.
- XLSX 특수문자·중복·대소문자·31자 제한·미배정 시트명 충돌·빈 목록·퇴원 제외, 1,050행 파일 쓰기/재읽기.
- 파일 입력의 cancel 이벤트가 선택 파일 표시/변경 콜백을 바꾸지 않는지 확인.
- 문자 공급자 오류·부분 실패·예약 시각 및 번호 정규화는 Solapi SDK 모의 처리로 확인. 실제 외부 발송 없음.

## 수정

1. 학생 전체 목록 및 반별 명단 API를 500건씩 끝까지 조회하게 변경. 기존 권한 조건과 정렬에 고유 ID 순서를 유지한다.
2. 내보내기는 화면에 로드한 학생·등록 관계를 사용한다. 반별 추가 요청 실패로 학생을 미배정 처리하던 경로를 없애고, 유효·고유한 시트명을 만든다. 실패 안내도 추가했다. 기존 열 너비·헤더 고정·시트 색상은 유지했다.
3. 설정 저장의 네트워크 오류는 결과가 불명확하다는 점과 새로고침 확인 방법을 안내한다.

## 끝까지 확인하지 못한 항목

- 최종 인쇄/PDF 저장: 현재 in-app 브라우저는 Ctrl+P에도 인쇄창을 자동화 상태에 노출하지 않으며 PDF 출력 API가 없다. 페이지 크기·화면 렌더 확인까지만 완료. 실제 종이/PDF 출력 완료로 세지 않았다.
- 운영체제 파일 선택창 취소: 도구에는 파일 지정 API만 있고 취소 API가 없어 실제 취소는 미검증. cancel 이벤트 회귀 테스트는 통과했다.
- 실제 문자 수신: 테스트 수신 번호가 없어 발송하지 않았다. 요청한 번호 확인 질문은 남겨 두었다.
- 실제 운영 계정 저장·Vercel 임시 환경변수 정리는 개발 기능 검증 범위 밖이며 이번에 변경하지 않았다.
