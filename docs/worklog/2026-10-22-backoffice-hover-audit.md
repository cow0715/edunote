# 백오피스 라이트·다크 hover 점검 (2026-10-22)

## 수정

- 공용 ghost Button의 dark:hover 반투명 배경이 개별 hover 색을 덮는 규칙을 제거했다. 기본 accent와 의미별 개별 hover를 양쪽 테마에서 사용한다.
- 학생 관리/성적표/채점/문항·단어 목록의 hover:bg-gray-50 계열을 control-bg로 교체했다. 기존 다크 호환 규칙이 hover를 캔버스 색으로 어둡게 만들던 문제를 피한다. 개발자 비교 도구와 공개 share 화면은 대상에서 제외했다.
- 학생 현황 선택 행은 aria-selected와 별도 선택 배경을 사용해 hover 중에도 선택 표시를 유지한다.
- 학생 현황 반, 클리닉 반/요일/출석, 성적표 종류/수신자, 모의고사 학년/시험/학생/답안/수신자, 수업 구분/요일 선택에 aria-pressed와 범위를 제한한 공통 hover 스타일을 적용했다. 선택 상태의 의미 색은 유지하며, 작은 회색 버튼은 중간 hover 톤을 사용한다.
- 수업 폼의 선택 버튼은 control-selected/control-on-selected를 사용해 다크의 밝은 primary 바탕 위 흰 글자 문제도 함께 정리했다.
- 메시지 발송 바로가기의 파란 그림자 hover를 중립 배경 변화로, 기출문제 목록 제목 영역의 빠진 hover를 배경 변화로 정리했다.
- 개별 성적표 전송 및 시험 변형 분석 실행 버튼은 action variant를 사용해 기본 버튼의 hover가 실행 버튼 색을 바꾸지 않도록 했다.
- 모의고사 채점 내부 2열 전환을 더 넓은 화면에서 적용하고, 답안 칸은 컨테이너 폭에 맞춰 줄바꿈한다. 1280px에서 수동 답안 버튼 너비가 0이던 상태를 실제 95.6px로 복구해 클릭/hover를 확인했다.

## 실제 개발 화면 검증

- 학생 관리: 가상학생 A 수정창 열기/취소와 행 hover, 라이트 F2F4F6 및 다크 24242B 확인.
- 학생 현황: 반 필터 선택/비선택, 학생 행 선택과 상세 패널 열기/취소를 양쪽 테마에서 확인.
- 성적표 발송: 수신자 선택/해제와 hover 대비를 양쪽 테마에서 확인. 생성/전송 실행하지 않음.
- 모의고사: 개발 DB에 합성 시험 2개·문항 4개를 잠시 준비해 시험·학생 선택, 수동 답안의 선택/해제, 라이트·다크 hover와 실제 클릭 가능 폭을 확인. 성적 저장/OCR/발행/전송은 실행하지 않았다. 검증 후 이 작업이 만든 시험 ID 33236897-3376-474a-a54e-991b21aab1d4, 18299773-a04c-475e-8524-5989d686518b만 삭제했고 남은 시험/성적 결과 모두 0건임을 SQL로 확인했다.
- 클리닉: 반 필터와 요일 설정 펼침/접힘, 선택을 유지한 비선택 hover 확인. 신청/출석 저장하지 않음.
- 기출문제 은행: 실제 시험 목록 카드 hover가 라이트 F2F4F6/다크 24242B로 바뀜을 확인. 단어장은 데이터가 없어 빈 상태와 코드 점검으로 구분한다. 생성/해설/판독 실행하지 않음.
- 문제 유형: 독해 유형을 펼쳐 소분류 행 hover를 양쪽 테마에서 확인. 편집/삭제/초기화 실행하지 않음.
- 메시지: E2E 반의 실제 발송 바로가기 hover와 시트 열기/취소를 양쪽 테마에서 확인. 시트 기본 데이터 조회 POST는 mode=data이며 유료 AI mode와 발송은 실행하지 않음.
- 수업 폼: 구분·요일을 선택하고 취소. 라이트 흰 배경/191F28 글자, 다크 2D2D35 배경/E5E8EB 글자 확인. 새 수업 저장하지 않음.
- 공용 메뉴·사이드바·설정/PDF 처리 화면은 스타일 코드도 함께 점검했다. PDF 처리·AI 작업 실행은 검증 범위에서 제외했다.
- React 검토: 선택 상태를 기존 state에서 직접 표시하며 hook/저장 로직 변경 없음. CSS Module은 필요한 백오피스 선택 UI에만 적용한다. 키보드 focus-visible과 선택 aria 속성을 유지한다.

스크린샷은 작업 시각화 폴더의 backoffice-mock-hover-light.png, backoffice-mock-hover-dark.png, backoffice-types-hover-dark.png에 보관한다. 필수 검사와 운영 배포 결과는 작업 응답에 기록한다.
