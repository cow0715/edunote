# 모바일 성적표·미저장 판정 보호

## 범위

- codex/teacher-workflow 브랜치의 7aa01ed 후속 변경이다. 메인 병합 없이 개발 Preview에 배포한다.
- 768px 미만은 학생 카드, 이상은 기존 표를 사용한다. 데이터와 학생별 답안 시트는 기존 GradeGrid의 상태/저장 경로를 공유한다.
- 모바일 카드에서 출결, 단어/시험 점수, 숙제, 메모를 확인하고 편집한다. 0점/미채점/미응시를 구분하고 결석·저장 중 입력을 막는다. 숙제 빈 값은 null, 0은 0으로 저장한다.
- 미저장 판정이 있으면 같은 창의 링크 이동 전에 앱 대화상자를 띄운다. 이동 취소는 현재 판정을 그대로 유지한다. 이동 승인 자체로 성적을 저장하지 않는다.
- 회차별 판정은 같은 탭의 세션 저장소와 메모리에 보관하고 1시간 이내에 복원한다. 복원/저장 전 원본 문항·답안·확정 상태를 비교해 오래된 판정의 적용을 막는다. 저장 성공/전체 취소 시 임시 판정을 제거한다.
- 실제 성적과 별개인 임시 정보다. 탭을 닫거나 저장소를 사용하지 못하면 복원을 보장하지 않는다. API/스키마/운영 환경변수 변경은 없다.

## 검증 구성

- 기존 SubjectiveReviewPanel 회귀와 새 이동 취소·재마운트 복원·저장 후 제거·원본 변경 시 저장 차단.
- 캐시 회차 분리, 기준/답안 변경, 다른 작업에서 확정 상태가 바뀐 답안 제외, 1시간 만료, 저장소 오류/손상, 모듈 재로딩 후 세션 복원.
- 모바일 카드 0점 표시, 단어/시험 시트 연결, 출결 갱신, 숙제 0/null, 메모 저장, 결석/저장 잠금.
- 가상 데이터를 사용한 임시 개발 페이지에서 실제 GradeGrid를 렌더링한다. API는 모형 응답만 사용하고 유료 POST 채점은 차단한다. 이 검증 페이지는 배포에 포함하지 않는다.
- 처음 전체 검사에서는 변경과 무관한 분석 UI 테스트 2개가 5초 제한을 넘었다. 메모리/CPU 경합을 줄이기 위해 개발 서버를 멈추고 --maxWorkers=2로 재검증한다.

최종 검사·브라우저 결과·배포 상태는 검증 후 아래에 기록한다.

## 브라우저 확인 범위

- 실제 GradeGrid 가상 페이지에서 모바일 카드의 0점/숙제/메모 표시, 소수 숙제·메모 입력 및 PATCH 모형 응답, 결석 시 답안 열기 차단, 기존 시험 답안 시트 연결을 확인했다.
- PC에서는 표 형태 유지와 메모 입력·blur 저장 모형 응답을 확인했다.
- 브라우저 자동 클릭/키 입력이 일부 버튼에 반영되지 않는 도구 문제가 발생했다. 새 탭·자동화 연결 초기화·접근성 액션으로도 해결되지 않아, 최종 앱 대화상자의 이동 승인 후 뒤로가기까지 연속 브라우저 검증과 새 화면 캡처는 완료하지 못했다. 이 범위는 통과로 기록하지 않는다. 앱 대화상자 취소·재마운트 복원·세션 복원·오래된 판정 차단은 자동 회귀로 검증한다.
- 임시 QA 페이지와 개발 서버는 정리했다. 실제 DB 성적이나 유료 AI는 호출하지 않았다.

- 숙제 입력 후 바로 미제출로 바꾸거나 다른 입력으로 이동할 때 PATCH 완료 순서가 뒤집히지 않도록 회차별 저장을 직렬화했다. PC와 모바일이 같은 훅을 사용한다. 늦은 이전 요청이 최신 값을 덮어쓰는 회귀를 실제 mutation 스케줄링 테스트로 확인한다.

## 후속 이동 E2E 완료 (2026-10-22)

- 위의 브라우저 검증 미완료 항목을 재검증했다. 사용자가 직접 연 Chrome localhost 개발 탭에서 자동 입력의 React 상태 반영과 버튼 클릭이 정상 작동했다. 이전 IAB 자동 입력/클릭 장애의 원인은 제품 결함으로 확인되지 않았으며 도구 장애를 제품 수정으로 기록하지 않는다.
- 실제 SubjectiveReviewPanel과 Next Link 라우팅을 사용하는 임시 개발 페이지로 검증했다. 학생 2명은 가상 데이터이며 API를 모형 응답으로 제한해 실제 DB 쓰기와 AI 호출을 차단했다. 실제 배포 환경 DB 저장의 추가 E2E를 수행했다는 의미는 아니다.
- PC: 정답/오답 2건 지정 → 링크 이동 대화상자 → 계속 검토 시 URL/판정 유지 → 저장하지 않고 이동 시 목적지 전환 → 브라우저 뒤로가기 시 복원 안내와 각 판정 2건 유지.
