# PDF 문항 매핑·답안 사진 저장 main 반영

- 최신 main의 비용 대시보드·촬영·검토·UI 변경을 보존하고, 운영에서 검증한 PDF 매핑 및 사진 저장 변경만 통합한다.
- PDF 문항은 객관식/서답형의 원래 번호와 소문항을 독립 식별하며 PDF 배치 순서를 표시한다. 공통 지문은 그룹으로 묶고 목록 및 소문항 누락 검증 실패 시 저장을 중단한다.
- 답안 보존 재파싱에서는 기존 문항·정답·학생 답안의 변경을 검증하고, 삭제·재채점 옵션과 함께 사용할 수 없도록 한다.
- 사진은 학생의 수업 소속 확인 후 Storage 업로드 → 학생 사진 경로 DB 저장 및 반환 경로 확인 → OCR 순서로 처리한다. 저장 또는 학생 연결 실패는 화면에 오류를 알리고 OCR을 호출하지 않는다. OCR 실패 후에도 저장된 사진을 유지한다.
- 기존 운영 검증에서 실제 사진의 정상 OCR 및 지원하지 않는 형식의 오류 경로를 확인했다. 실패 후 재다운로드 바이트가 입력과 같았고, 원래 답안 7,753개와 점수 645개 해시는 동일했다.
- migration 20261022000001_question_pdf_presentation.sql은 개발·운영 DB에 이미 적용돼 있다. 이 커밋에는 동일한 스키마 파일도 포함해 저장소와 DB 구조를 일치시킨다.
- main 푸시 후 Vercel의 Git 자동 배포가 이 커밋을 소스로 사용하고 운영 도메인에 연결되는지 확인한다. 검증용 개인 사진과 백업 파일은 커밋하지 않는다.
- 커밋 대상에서 직접 실행한 npm run check: 130개 파일 / 1,253개 테스트 통과, 린트 오류 0개. 기존 warning 21개 유지. 유료 LLM 파싱 테스트는 실행하지 않았다.
