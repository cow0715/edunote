# 교재 캐시 보호와 대표 구간 확인 대기

- 범위: 영독 상·수완 유형·수완 실전의 기존 작업. 영독 하는 등록된 120문항을 유지하고 재처리에서 제외한다.
- 기존 매핑·원본 검증·풀이·어휘 보완 응답과 원본 파일은 삭제하거나 덮어쓰지 않는다. 파일·묶음 예산도 변경하지 않는다.
- 수완 유형 10강 2번의 문장부호, 실전 1회 41·42번의 공유 소재 연결은 기존 검증 통과 캐시를 그대로 승인하지 않는다. 정확한 PDF·지문 해시로 범위를 제한하고 새 진행 상태 키를 사용한다.
- 이미 받은 교정 응답은 원문 해시가 정확히 일치할 때 후보 구성에 재사용한다. 후보 생성은 검증 통과가 아니다. Sonnet 원본 이미지 대조를 다시 통과해야 풀이·어휘 보완과 등록으로 진행한다.
- 대표 구간 1~6개는 첫·끝 지문, 공유 지문, 여러 페이지 연결, 형식별 구간, 모호한 연결을 포함한다. 검증·보완이 모두 끝나면 `pilot_review`에서 워커가 종료한다. 자동 전체 확대와 예약 재개는 없다.
- 확인 화면에서 대표 문항, 완료·잔여 지문 수, 누적 사용액·예약액·파일 상한을 제공한다. 기존 응답만으로 끝낸 대표 구간을 유료 호출의 단가 0으로 확대 추정하지 않는다.
- 승인 RPC는 소유권·문항 버전·검증 기록·예산 설정이 동일한지 확인한다. 승인만 저장하고 작업은 failed 상태로 유지한다. 전체 처리는 별도 재개 버튼이 필요하다.
- DB에서도 승인 없이 bulk 전환·등록 확정·제외된 교재의 새 작업 생성을 차단한다. 기존 기출·주차별 처리는 이 게이트를 사용하지 않는다.
- 마이그레이션: `20261101121520_book_source_pilot_review.sql`. 테이블 보조 컬럼과 RPC·트리거만 추가하며 기존 데이터 DML은 포함하지 않는다.
- 이번 릴리스는 큐 PAUSED, `PDF_IMPORT_CACHE_ONLY=true`, 워커의 Anthropic 키 미연결을 유지한다. 작업 실행·재개·유료 테스트는 별도 요청 전까지 금지한다.

검증: 합성 자료 기반 유닛테스트, PGlite에서 SQL 재적용·권한·우회 차단·수동 승인, 기존 응답을 읽기만 하는 두 구간 오프라인 검사. 원문 본문 전체와 운영 응답 파일은 저장소에 포함하지 않는다.

사용자가 이번 SQL의 개발·운영 직접 적용을 명시적으로 승인한 후 양쪽 DB 적용 완료. 적용 전후 기존 체크포인트·문항·문서·예산·요청별 비용·배치 기록 해시 동일. 운영 체크포인트 3,709건 보존, 영독 하 120문항 유지. 작업 상태·실행 예약·리스는 변경하지 않았다. 기존 작업의 제외 표시와 두 구간 보류 사유만 별도 메타데이터로 연결했다. 새 RPC는 service_role 전용이며 SECURITY INVOKER와 고정 search_path를 확인했다.
