# 등록·처리 UI 적용 위치 정정

- 자료 목록의 교재 전용 열람 UI를 제거하고 기출과 동일한 QuestionCard 목록을 사용한다.
- 등록·처리 탭에서 교재 선택 → 현재 저장된 문항 수 → 미저장 사유·원본 → 비용 내역 순서로 확인한다.
- 지문·정답·해설 열람과 편집은 기존 자료 목록으로 연결한다. 과거 자동 처리 기록과 현재 저장 결과를 구별한다.
- 영독(하)는 문서의 exam_bank_id가 비어 있고 상태가 processing으로 남아 있지만 복구 문제은행에 실제 116문항이 존재함을 읽기 전용 SQL로 확인했다. 해당 복구 기록의 연결값으로 실제 문항을 조회하고, 실패한 작업을 처리 중으로 표시하지 않는다.
- 교재별 실제 저장된 source_key를 기준으로 과거 보류 기록에서 저장 완료 문항을 제외한다. 오류 시 0건으로 단정하지 않는다.
- DB 변경, 처리 작업 재개, 유료 AI 호출, PDF 업로드, Git 커밋/푸시는 하지 않는다.
- 동시 작업 중인 처리 엔진 변경을 제외하기 위해 HEAD(a6efde246) 기반의 UI 전용 배포본을 `tmp/registration-ui-release`에 구성했다.
