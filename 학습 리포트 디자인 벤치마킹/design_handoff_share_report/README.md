## Overview

### 영역 요약·시안 선택 정리 (2026-10-01, 아래 시안 선택보다 우선)
- 영역 요약은 중립 가로 막대를 유지한다. 영역 수가 기록에 따라 1개부터 달라지고 문항 수도 서로 다르므로 레이더의 면적/형태로 능력 균형을 표현하지 않는다. 선택 기간 누적 정답률과 실제 정답/문항 수를 함께 읽도록 한다.
- 영역에 포함된 유형은 각 행의 ‘포함된 유형 N개’에서 펼쳐 확인한다. 긴 유형 목록은 기본 화면에서 덜어내며, 영역별로 없는 표본 판정 기준을 추가하지 않는다.
- 사용자 시안의 상단 선택 이름은 ‘학습 상황’이다. 기본 분석·기록 부족·최근 오답 증가·최근 회복·모두 정답 다섯 사례로 정리한다. 긴 이름/26회/동률 등 검증용 사례는 검토 메뉴에서 제거하며 해당 로직의 유닛 검증은 유지한다. 데이터는 가상 기록임을 명시한다.

### 분석 직관성 시안 (2026-10-01, 아래 분석 레이아웃보다 우선)
- 분석 탭은 첫 해석·복습 제안 → 전체 유형의 누적 상태 개수 → 먼저 확인할 최대 세 유형 → 접힌 유형별 최근 흐름 순서로 읽는다. 일반적인 카드 배경·색상·폰트·모바일 폭은 유지한다.
- 전체 유형의 우선 보완·복습 권장·안정적·기록 부족은 상단의 카드 없는 두 열 요약으로 보여준다. 숫자는 유형 수임을 표시한다. 상태를 누르면 해당 목록을 열고, 검색·상태 필터·여덟 개 이후 더 보기·접기·기간 변경 초기화를 유지한다.
- 먼저 확인할 유형은 Recharts 가로 막대로 선택 기간 누적 오답률을 비교한다. 길수록 오답이 많다. 실제 오답 수/문항 수로 계산하고 표시만 반올림한다. 모든 막대는 0–100% 공통 범위이며 축·범례·별도 툴팁 없이 이름과 실제 숫자를 HTML로 함께 읽을 수 있다. 세 유형이 같은 결과일 수도 있으므로 순위 번호나 ‘가장 약한 유형’을 붙이지 않는다.
- 각 추천 행은 유형명·누적 오답률·문항 중 오답 수·짧은 이유와 명시적 오답 보기 액션을 통합한다. 기록 부족은 중립색·판정 보류, 누적 안정/최근 주의는 최근 묶음 정답률과 확인 이유, 회복 후 남은 오답은 이전 오답 확인으로 구분한다. 긴 이름은 잘라 숨기지 않는다. 전체 유형 목록은 누적 정답률을 유지하며 두 범위를 라벨로 구분한다.
- 유형별 최근 선그래프는 기본 접힌 독립 상세 안에 둔다. 기존 유형 선택·최근 최대 여섯 실제 점·최근/직전 네 회차 합산·비교 표본 조건·전체 수치·오답 이동을 보존한다. 회차별 변화·영역 요약·계산 근거도 각각 독립 펼침으로 유지한다.
- 가상 전체 시안에는 다른 정답률의 24개 유형 비교 사례를 별도로 추가한다. 기존 동률·짧은 기록·만점·미분류·빈 기록·긴 이름·26회 기록을 보존하고 충분한 최근 주의·회복 사례를 추가한다. 운영 계산·DB/API는 바꾸지 않는다.

### 분석 표본·누적 기준 보완 (2026-10-01, 아래 분석 계산 기준보다 우선)
- 유형의 우선 보완·복습 권장·안정적 분류는 선택한 학습기간 전체의 정답/문항 수로 판정한다. 최소 3회 출제·10문항 미만은 기록 부족이다. 기간 누적 비율의 60%·80% 경계는 반올림 전 비율을 사용한다. 추천과 전체 목록의 큰 숫자 및 분모도 기간 누적으로 표시한다.
- 최근 결과는 실제 출제 최근 최대 4회, 이전 결과는 그 바로 앞 최대 4회다. 양쪽 각각 3회·10문항 이상이어야 변화량과 개선을 표시한다. 개선의 15%p 경계도 실제 비율로 판정한다. 부족할 때는 실제 그래프·문항 수를 표시하고 비교 판정을 보류한다. 최신 두 회차 차이를 개선·약점의 근거로 쓰지 않는다.
- 충분한 최근 기록이 80% 이상이면 누적 약점이라도 적극 보완 추천에서 제외한다. 기간 누적이 안정적이지만 충분한 최근 기록이 60% 미만이면 ‘최근 결과 확인’ 근거와 함께 먼저 안내한다. 강점은 누적과 충분한 최근 기록이 모두 안정적이고 최근 각 회차도 80% 이상일 때 소개한다.
- 추천은 현재 확인할 유형을 최대 3개로 제한하며 기간 오답 합집합·반복 회차·출제 수를 고려한 순서를 유지한다. 보완할 유형이 없으면 기록 부족의 실제 오답, 그 뒤 남아 있는 기간 오답을 확인하도록 안내한다.
- 3회·10문항·비율 기준은 학생의 복습 안내를 위한 설명 가능한 제품 규칙이다. 신뢰도를 보장하는 통계적 판정이나 고정된 실력으로 표현하지 않는다. 기록 부족에도 전체 수치와 오답 접근을 보존한다. 승인된 전체 분석 탭 레이아웃·색상·표면·독립 펼침은 유지한다.

### 분석 전체 시안·조작 정리 (2026-10-01, 아래 분석 구조보다 우선)
- 기본 흐름은 짧은 해석 → 먼저 복습할 유형 → 유형별 정답률 흐름 → 전체 유형 상태 요약이다. 추천은 최대 3행이며 유형명·최근 정답률·최근 문항 중 오답 수만 쓴다. 하락 폭과 긴 추천 근거를 여러 곳에 반복하지 않는다.
- 차트는 최근 최대 두 출제 회차의 합산 정답률·실제 정답/문항 분수·직전 묶음 대비 변화량을 그래프 위에 모은다. 그래프 자체는 회차별 정답률이다. 많은 유형의 선택 목록에 있는 일반 상태를 숫자 요약에 반복하지 않고, 개선·강점은 의미가 있는 별도 안내를 유지한다.
- 전체 유형 카드에 우선 보완·복습 권장·안정적·기록 부족의 개수를 2열로 기본 표시한다. 상태를 누르면 해당 목록이 열리고 기존 검색을 초기화한다. 전체 목록 열기와 접기는 목록 위에서 조작한다. 검색·상태 필터 조합과 기본 8개 이후 더 보기를 유지한다. 카드 안 입력은 내부 박스 토큰을 따른다.
- 전체 분석을 한 번에 펼치는 구조를 없애고 회차별 변화·영역별 요약·분석 기준과 추천 이유를 각각 독립적으로 펼친다. 오답 집중도는 복습 카드 아래의 짧은 문항 수 요약을 누르면 확인한다. 실제 오답 문항·소표본 안내·분류 계산은 보존한다.
- 사용자 검토용 전체 시안은 실제 분석 컴포넌트를 가상 기록으로 렌더링한다. 기본은 24개 유형이며 검토 도구는 보고서 밖에 둔다. 분석 탭만 제공하고 모바일 최대 430px·토큰·무그림자 표면을 유지한다.

### 많은 유형 분석 보완 (2026-10-01, 아래 분석 구조보다 우선)
- 첫 화면은 짧은 해석 → 먼저 복습할 유형 → 선택한 유형의 정답률 흐름이다. 오답 범위는 복습 카드 아래의 짧은 보조 정보로 통합한다. 많은 유형의 수치와 근거를 한꺼번에 펼치지 않는다.
- 최근 실제 두 출제의 합산이 3문항 미만이면 기록 부족이다. 충분한 기록에서 정답률 60% 미만은 우선 보완, 60~80% 미만은 복습 권장, 80% 이상은 안정적으로 구분한다. 60~80% 미만이 직전 묶음보다 15%p 이상 낮아지면 우선 보완이며, 하락 비교에는 두 묶음 각각 3문항 이상이 필요하다. 경계는 반올림 전 비율로 판정한다.
- 추천은 보완할 유형 최대 3개와 실제 오답 근거로 제한한다. 우선 보완·복습 권장 유형이 있으면 안정적/기록 부족 유형을 섞어 추천 수를 채우지 않는다. 보완할 유형이 없을 때만 기록 부족의 오답 확인, 그마저 없으면 안정적인 유형의 남은 기간 오답 확인으로 안내한다.
- 전체 유형은 기존 기본 접힘에 보존하며 이름 검색·상태 필터·분류별 간결한 목록으로 조회한다. 행은 유형명·최근 정답률·최근 정답/문항 수·기간 오답 수를 보여주고, 오답이 있으면 기존 유형별 오답 조회로 이어진다. 기본 8개 이후는 더 보기다. 기록 부족을 약점으로 단정하지 않는다.
- 선 그래프는 설치된 Recharts를 사용한다. 많은 유형은 하나의 선택 목록에서 찾고, 한 번에 한 유형만 표시한다. 고정 0–100%, 실제 최근 최대 6회, 날짜·문항 분모·전체 수치·소표본 안내를 유지하며 툴팁은 누르거나 방향키로 조회한다. 라이브러리는 분석 탭을 열 때 불러온다.

### 분석 그래프·가독성 보완 (2026-10-01, 아래 분석 구조보다 우선)
- 기본 화면은 짧은 추천 → 유형별 정답률 추이 → 복습 순서 → 오답 범위의 3개 카드다. 긴 추천 이유·유형별 막대·회차별 상세 비교·영역 목록·계산 기준은 ‘전체 유형·영역 분석’에 접어 보존한다.
- 추이 그래프는 우선 복습·개선·강점 중 최대 3개 유형을 선택해 한 번에 한 유형만 표시한다. 최근 최대 6회 실제 출제를 직선으로 잇고 y축은 항상 0–100%다. 실제 날짜와 ‘출제 회차 순’을 표시해 날짜 간격으로 오해하지 않게 한다. 미출제 회차를 0%로 채우지 않는다.
- 한 회차는 점 하나와 비교 전 안내를 보여준다. 긴 기간은 표시 범위와 전체 회차 수를 안내하고 모든 수치는 펼침에서 확인한다. 차트의 회차별 정답률과 최근 두 회차 합산 정답률은 라벨로 구분한다.
- 유형 선택에서 개선·강점을 알려 별도 설명 카드를 반복하지 않는다. 복습 행은 유형명·최근 오답 분수·반복 상태로 간결하게 쓰고 자세한 이유는 펼침으로 옮긴다.
- 오답 분할 막대는 추천 상위 2개 유형에 포함된 오답 합집합과 그 외의 2개 구간이다. 문항 수를 막대 밖에 함께 표시하고 그 외 0문항도 텍스트로 유지한다. 유형별 원형 그래프는 다중 태그가 중복되므로 사용하지 않는다.
- 모바일 폭·공용 Card·색상·타이포 토큰을 유지한다. 일반 선택은 중립색, 긍정/주의는 의미 색상을 사용한다. 정답률의 축소된 축이나 장식용 곡선으로 변화를 과장하지 않는다.

### 분석 인사이트 보완 (2026-10-01, 아래 기존 분석 사양보다 우선)
- 분석은 먼저 살펴볼 유형 → 기록에서 읽을 수 있는 점 → 복습 순서 → 전체 유형별 오답률 → 출제 회차별 변화 → 영역별 정답률 순서로 읽는다. 첫 제안은 기존의 카드 없는 제목·숫자·회색 액션을 유지한다.
- 복습 순서는 최근 두 실제 출제 회차에 오답이 남은 유형을 먼저 골라 최대 3개를 제안한다. 최근 표본이 2문항을 넘는 유형을 우선하고, 출제 수를 고려한 오답 비율과 오답 발생 회차 수로 정렬한다. 최근 오답이 없으면 누적 오답을 확인하도록 표현한다.
- 오답 집중도는 복습 상위 2개 유형에 속한 기간 오답의 합집합 / 확인된 전체 오답이다. 다중 태그 문항은 한 번만 센다. 전체 오답이 2문항 이하이면 집중도를 강조하지 않고, 추천 유형의 비중이 50% 미만이면 오답이 여러 유형에 나뉘어 있음을 안내한다.
- 최근 결과는 유형별 최근 두 출제 회차의 정답 수 / 문항 수로 합산한다. 직전 최대 두 출제 회차와의 비교는 두 묶음 모두 2문항을 넘고 정답률이 15%p 이상 높아졌을 때 개선으로 소개한다. 회차별 비율의 단순 평균을 사용하지 않는다.
- 강점 후보는 2회 이상 출제·5문항 이상·누적과 최근 각 출제 회차 정답률 모두 80% 이상인 유형이다. 확인된 결과임을 명시하고 문항 수·난도 차이를 함께 안내한다.
- 색상·표면·모바일 폭·타이포는 기존 토큰과 공용 Card를 따른다. 개선은 의미가 있는 파랑, 낮은 정답률은 빨강, 일반 액션은 회색이다. 상세 통계와 오답 조회를 유지하며 DB/API 변경은 요구하지 않는다.

### 백오피스 반·기간 관리 보완 (2026-09-29)
- 별도 전역 탭 없이 반 안에서 기간을 선택하고 관리한다. 조회 선택은 달력과 단어 내보내기만 바꾸며, 공유 기본 지정은 명시적인 확인 후 수행한다.
- 관리 목록은 우측 패널(모바일 전체 높이)로 옮긴다. 기간별 실제 날짜·수업 횟수·공유 기본 표시와 이름/날짜 수정·삭제 기능을 유지한다.
- 새 기간은 간단한 입력 후 기존 기간 종료와 새 공유 기본을 확인한다. 공유 기본 지정만으로 날짜 범위를 바꾸지 않는다.
- 수업 목록은 운영 중 / 보관된 반 / 전체 필터와 항상 보이는 관리 메뉴를 제공한다. 보관에 따른 공유·재시험 접근 변경을 설명한다.

### 분석 화면 보완 (2026-09-29, 아래 기존 분석 사양보다 우선)
- 학생·학부모가 최근 수업과 기간 누적 기록을 쉽게 읽는 것이 우선이다. 홈의 최근 수업·기간 요약과 5탭 구조를 유지한다.
- 분석은 복습 제안 → 유형별 오답률 → 출제 회차별 변화 → 영역별 정답률 순서로 읽는다. 첫 제안은 카드 없이 제목·숫자·일반 회색 액션으로 강조한다.
- “유형명, 함께 짚어볼까요?”는 실데이터 규칙으로 결정한다. 출제 수가 적을 때, 전부 정답일 때, 유형 미분류일 때, 문항별 결과가 없을 때를 구분한다. 가장 많이 틀렸다는 단정 대신 출제 수와 오답률을 함께 고려한다.
- 유형명은 줄바꿈하며 오답/전체 문항 수를 함께 표시한다. 상위 8개 이후는 더 보기로 제공하고 0% 오답 유형도 유지한다. 추천 유형 막대만 파랑으로 강조하고 나머지는 중립색을 쓴다.
- 변화는 같은 유형의 최근 두 출제 회차를 비교한다. 날짜·정답/출제 수를 함께 표시하고 모든 출제 회차 기록과 기존 패턴 설명은 펼침에서 확인한다. 기본 3개 이후도 더 보기로 제공한다. 미출제를 0%로 표시하지 않는다.
- 작은 레이더를 없애고 영역별 정답률·문항 수·포함 유형을 목록으로 보여준다. 같은 영역에 태그가 여러 개 있어도 한 문항은 한 번만 집계한다.
- 통계는 선택 기간 범위다. 관련 오답은 기존 유형별 오답 조회로 연결하고 홈의 기간 추이 그래프와 기존 시험·복습 기능은 유지한다.

### 문제 복습 가독성 보완 (2026-09-28, 아래 기존 사양보다 우선)
- 지문·선지·오답 원문은 16px/400/1.7–1.75, 왼쪽 정렬. 다시 풀기 발문은 17px/700/1.6, 해설은 15px/1.75다.
- 다시 풀기는 번호·발문 → 지문 → 원본 이미지 → 선지 → 결과·해설 순서다. 지문은 구분선으로 나누고 좌우 중첩 패딩을 없앤다.
- 문제·해설은 하나의 주 스크롤로 읽는다. 정답 확인 후 해설로 이동하고 ‘문제 처음으로’로 돌아갈 수 있다. 하단 주요 버튼에는 safe-area를 반영한다.
- 전체화면 복습은 모달로 열어 배경 스크롤·포커스를 차단한다. 결과는 성적에 저장되지 않는 개인 복습임을 안내한다.
- 기존 모바일 최대폭·테마 토큰을 유지한다. 바텀시트 재설계는 이 변경에 포함하지 않는다.

### UX 정확성 보완 (2026-09-28, 아래 기존 문구보다 우선)
- 홈은 과거 기간도 조회하므로 "최근 수업"과 실제 회차 날짜를 표시한다. 비교는 "직전 회차"로 표현한다.
- 요약 숫자는 기간 평균, 증감은 직전 회차 대비, 반 비교는 기간 비교로 명시한다. 증감과 반 비교는 각 값으로 색상을 정하며 모바일에서 비교 문구는 별도 줄로 배치한다.
- 지표 행은 "추이 보기/선택됨"으로 그래프 전환을 알린다. 화살표는 상세 화면 이동에 쓴다.
- 홈에서 오답 목록으로 가는 문구는 "오답 보기", 재시험 대기 단어장 이동은 "복습할 단어 N개 보기"다. 목록 이동에 고정 시험 시간을 표시하지 않는다.
- 단어 재시험이 모두 완료되면 홈 할 일에서는 해당 행을 제외한다. 오답 탭에서 기록은 계속 조회할 수 있다.
- 일시적인 조회 오류에는 재시도를 제공한다. 전체 기간 로딩·실패 시 선택 기간 데이터로 대체하지 않는다.

`src/app/share/[token]` 아래 학부모·학생용 리포트 화면을 재구성한 디자인입니다. 기존 5탭(홈/성적/분석/단어/오답) 기능은 전부 유지하되, 정보 구조를 **"이번 주 한 줄 → 할 일 → 기간 요약(리스트+그래프) → 코멘트"** 순으로 바꾸고, 색을 카테고리 구분에 쓰지 않고 **의미(파랑=선택/긍정, 빨강=주의)** 에만 쓰도록 정리했습니다. 데이터 스코프는 **선택한 기간(class_period)** 기준입니다.

## About the Design Files
이 폴더의 `.dc.html` 파일은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다. 그대로 복사해 배포하는 코드가 아닙니다. 기존 코드베이스(Next.js + Tailwind + shadcn + lucide, `src/app/share/[token]/*`)의 패턴과 컴포넌트(`Card`, `StatCard`, `AttendanceCalendar`, `SwipeChartCard`, `ScoreTrendChart`, `PatternCard`, `WrongAnswerCard`, `WrongVocabRow`, `VocabStudyWordCard` 등)를 **재사용·수정**해서 이 디자인을 재현하세요.

- `Weekly Report v3.dc.html` — 최종 디자인 (이걸 기준으로 구현)
- `report-data.js` — 프로토타입용 정규화 데이터. 실제 앱에서는 `useShareModel` 의 결과를 그대로 쓰면 됩니다. 이 파일은 **화면이 어떤 데이터 형태를 기대하는지** 참고용.
- Tweaks의 `dataset` 으로 3가지 실데이터 케이스(6주 목업 / 26주·시험 없음 / 새 기간 1주)를 전환해 엣지 케이스를 확인할 수 있습니다.
